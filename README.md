# genail-mods

[Claude Code mods](https://claude.dev/blog/getting-started-with-claude-code-mods/) by Genail.

## Install

In Claude Code (2.1.287 or later):

```
/plugin marketplace add genail/genail-mods
/plugin install task-progress@genail-mods
/reload-plugins
```

## Mods

| Mod | What it does |
|---|---|
| [task-progress](task-progress/) | Live progress bars above the prompt for background shells and subagents |

## Before you install

A mod runs inside Claude Code on your machine with the same access Claude Code has. Read its code first.
